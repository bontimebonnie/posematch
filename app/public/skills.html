在專案資料夾裡執行，第一行需要先裝好 Node.js。ux-copy 和 frontend-design 屬於外掛，請依上方連結的說明加入。Mobbin 需要帳號。

npx skills add addyosmani/agent-skills
claude mcp add mobbin --scope user --transport http https://api.mobbin.com/mcp

關鍵 prompt

以下是我當時實際輸入的原文，所以是粵語和英文。App 原名叫 Post Match，換成你自己的點子就可以用。

1. 開場：說清楚流程，並請它反問

不必先想好技術，把使用者流程講完整，再請它指出不清楚的地方。

我想要整一個 App，叫做「Post Match」。成個流程我會想知道我哋要用咩 framework 去整。我想完成個製成品之後，佢可以用電腦、手機或者平板玩到，可以係一個 Web App，但佢應該用咩 framework 去做？

佢嘅流程應該會係咁：
1. 開咗 App 之後，一係 upload 自己搵嘅卡通相，一係喺現有 library 入面重新揀之前 upload 過、save 咗落嚟嘅卡通相。
2. 喺揀相之前要揀幾多個人影。因為如果兩個人影，卡通相應該得兩個 character；三個人影就會有三個 character。我哋先整咗兩個 character 嘅 basic function 先，定係整唔整選擇住？你話畀我聽我應該點整。
3. 揀咗人數、upload 咗相之後，就去到影相嘅部分：
(a) 想參考嘅卡通示意圖喺畫面嘅上面，而我哋個 camera 就喺畫面嘅下面。
(b) 一次淨係影一張相，影完如果唔滿意可以重影，直到影得好為止。
(c) 影得好之後就去下一張，total 會影四張。
4. 出嚟嘅成果就好似我畀你嘅圖咁，一邊係卡通、一邊係真人，平排咁樣出，最後會有個 four-strip 嘅 layout。框框嗰啲嘢我哋先唔整住。

我哋先整咗咁多先。你話畀我聽咁樣可唔可行？又或者我應該分啲咩 step 去做到呢一樣嘢？

如果中間有咩問題，你想要再了解多啲關於呢個 App，你就話畀我聽，我再解答你嘅問題，等我哋可以好順暢咁 build 到個 App。

2. 定順序和標準：功能先，設計後（節錄）

告訴它「成功」的樣子和審美底線，後面的規格才有依據。

至於「成功」係點樣？我覺得最主要係可以整到個靚靚嘅 app。所謂靚，喺我自己嘅美觀標準上，要有一定嘅 design guideline、唔同嘅 aspect，同埋 spacing 一定要跟 8-grid spacing。

如果返去頭先跳過咗嘅 step，我哋係咪可以跟返應有嘅步驟去做？先試晒啲 basic function，跟住先再做 design？

3. 研究：走完別人的流程，找出自己缺什麼

給它實際的網站，比泛泛地問「拍貼 App 應該有什麼」有用得多。

https://photobooth.nashallery.com/ https://wheephotobooth.com/ https://mysketchbooth.com/ get all the flows and see what screen we are missing. and what we can learn from those.

4. 開工節奏：每次只做一段，到點就停

這句我用了整個專案。任務編號換成你計畫裡的就好。
