# Figma 畫框 brief（Phase C frames）

你喺 Figma 設計框，我負責寫入 app。呢份講清楚畫布尺寸、相格點縮、同我要收啲乜。

## 1. 畫布

- 每個框一個 Figma Frame，**1080 × 1350 px**（Instagram 4:5），名叫 `frame/<id>`，例如 `frame/pastel`。
- 入面永遠係 **4 行 × 2 格**（左卡通、右真人），每格比例 **3:2**，格與格之間 gap **12 px**，上下左右置中。
- 相格係「窿」：你畫嘅框喺相格以外，相格位留透明（或者放一個灰色 placeholder 矩形，export 前 hide）。

## 2. 相格尺寸：由上下留白決定

框要留位就要縮細相格。因為 strip 係「高」嘅（8 格疊埋比畫布更高身），**上下留白（top + bottom inset）先係卡住相格大細嘅數**，左右會自動多出餘位。公式：

```
cellH = floor((1350 − top − bottom − 36) / 4)     // 36 = 3 個 gap
cellW = floor(cellH × 1.5)
stripW = cellW × 2 + 12
側邊留白 = (1080 − stripW) / 2
```

幾個 preset，揀一個直接用（top/bottom 可以唔對稱，例如下面大啲放標題，加埋等於同一個總數就得）：

| top + bottom 總數 | 例子 (top, bottom) | 相格 (W×H) | strip 闊 | 側邊留白 |
|---|---|---|---|---|
| 18（無框，而家） | 9, 9 | 486 × 324 | 984 | 48 |
| 96 | 48, 48 | 456 × 304 | 924 | 78 |
| 144 | 72, 72 | 438 × 292 | 888 | 96 |
| 192 | 96, 96 ／ 72, 120 | 420 × 280 | 852 | 114 |
| 240 | 120, 120 ／ 96, 144 | 402 × 268 | 816 | 132 |

Figma 做法：畫一個 1080×1350 Frame → 放 8 個灰色矩形（用上面嘅 W×H、gap 12，整體置中）→ 鎖住 → 喺佢哋以外畫框。側邊留白如果嫌多，框嘅左右部分可以畫粗啲，或者加少少「探入」gutter 嘅裝飾。

## 3. 可以同唔可以

- 可以：框元素少少疊到相格邊（膠紙角、絲帶），因為測試只 check 相格**中心**。
- 可以：相格之間嘅 gap 畫花紋、改底色。
- 唔可以：遮住相格中間；改畫布尺寸；用真正 Chiikawa 版權圖做預設素材。
- 無框永遠係預設，輸出同而家一粒 byte 都唔變。

## 4. 我要收嘅

每個框：

1. **Export**：PNG 1080×1350 @1x，相格位透明（簡單幾何框用 SVG 更靚，但 PNG 一定得）。或者直接俾 **Figma file link**，我用 Figma MCP 自己讀 node 同 export。
2. **四個 inset 數**（top / right / bottom / left），或者話我知用邊個 preset。
3. **名**：中文 + 英文（tray 顯示用，例如「粉彩邊 / Pastel」）。
4. **相格以外嘅底色**同 **gap 顏色**（如果 PNG 已經包埋就唔使）。

有幾多個框都得，第一批 2–3 個夠起步。
